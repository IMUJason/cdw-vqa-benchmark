## 关键发现
1. **API 旗舰同样崩塌且更狠**：实例 pipes 材质 0.03–0.05（vs 开源零样本 0.11–0.60、人类 0.80）；
2. **劫持签名的矿物变体**：GLM API 把白色管段答成 Quartz/Pottery/Ceramic/Rock（开源模型是 bone/cigarette 日常物体变体）——两族劫持词不同但现象同构：**没有材质答案可用时，模型逃向各自先验里最近的具体类名词**；
3. GLM API 场景 F1（.45–.53）反而低于 GLM 本地 9B（.46–.78）——端点可靠性+提示差异需谨慎解读，论文只做定性声明。

## 打分教训（论文 methods 附注）
- API 模型答案常带 markdown 粗体（`**Yes.**`），首词解析须先剥星号；
- unable 措辞多变（unable to view / don't see an image / only see a link），须宽正则；
- 图像投递失败与模型能力失败必须分离计数。
